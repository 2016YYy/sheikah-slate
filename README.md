希卡石板（灵感源自游戏中的 Sheikah Slate / 希卡石板）是一款面向《塞尔达传说：旷野之息》玩家的**完全离线**图鉴与攻略工具：武器、防具、神庙、任务、料理、材料、怪物与攻略手册全收录，无需联网即可查阅，支持打勾记录收集进度、收藏与统计。

## ✨ 功能特性

- **完全离线运行** — 所有数据内嵌在应用中，不依赖任何网络请求、CDN 或在线资源
- **打勾收集记录** — 武器 / 防具 / 神庙 / 任务 / 怪物 / 材料 / 料理逐项打勾，`localStorage` 本地持久化
- **分类筛选与搜索** — 全部 / 已获 / 未获切换、按类型与地区筛选、跨分类关键词搜索
- **收藏夹** — 心仪条目一键收藏，按分类聚合浏览
- **全进度统计** — 环形总进度、分类进度条、高塔 / 回忆 / 克洛格果实 / 任务分项统计，支持「只看未完成」
- **应用内检查更新** — 基于 GitHub Releases，发现新版本时弹出更新提示（可选联网功能，离线静默跳过）
- **希卡风格 UI** — 希卡蓝 + 圣三角金配色，自绘希卡符文图标与翻页动画，适配移动端与桌面端

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 生产构建
npm run build

# 预览构建产物
npm run preview
```

构建产物输出至 `dist/`，可部署到任意静态托管（GitHub Pages、Vercel、Netlify 等）。

## 🧰 技术栈

- **React 19** + **TypeScript**
- **Vite 6** — 构建与开发服务器
- **Tailwind CSS v4** — 希卡主题样式
- **React Router 7** — 路由
- **Framer Motion** — 页面过渡动画
- **Radix UI** — 无障碍基础组件
- **Sonner** — Toast 通知

## 🔄 应用内检查更新

应用内置版本号 `v1.0.0`。「关于」页点击「检查更新」会查询本仓库的 GitHub Releases 最新版本：

- 发现新版本 → 弹出更新提示（版本号 + 更新说明 + 跳转 GitHub 下载）
- 无网络或不是最新 → 静默提示，不影响离线使用

发布新版本时，为仓库创建带版本号的 Release 即可（tag 如 `v1.0.1`）。
